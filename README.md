## Selected projects

Built with ASP.NET Core, SQL Server, Clean Architecture, Azure Document Intelligence, Azure Blob Storage, API-key protection, rate limiting, OpenAPI documentation, file-upload validation, structured error handling, and xUnit coverage.

### TravelPricingGateway
ASP.NET Core hotel pricing API that validates hotels through SQL Server, calls multiple pricing providers in parallel, supports both JSON and legacy XML provider formats, and returns the cheapest successful result.

Production-used .NET 8 employee scheduling optimizer built for a real operations workflow.
